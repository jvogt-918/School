Exercise 1: Conceptual Questions

A. Name at least two advantages that logistic regression has over LDA.

  1. Logistic Regression have better fit with real-world data due to not assuming that predictors are normally distributed.

  2. Logistic regression are able to work with non-linear relationships between predictors and response through transformations and interactions.

B. Does logistic regression predict the binary outcome or does it predict something else? Explain.

Logistics Regression doesn’t predict an outcome, it predicts the probability of an binary outcome. The output of a logistic regression will give you a value between 0 and 1, which would represent the probability of a binary outcome.

###C. True or false? Multicollinearity is not typically an issue with LDA. However it is still an issue for logistic regression.

True, multicollinearity affect logistic regression more than a LDA model would. Having coefficients with high multicollineariyt could ead to unstable model results.

D. Briefly explain the separability problem that multiple logistic regression can sometimes suffer from.

IN rare cases, when predictor variables seperate groups perfectly, logistic regression struggles. This is because coefficients go to infinity, which makes estimating impossible.
